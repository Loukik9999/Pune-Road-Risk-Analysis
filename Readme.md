# Pune Road Risk Analysis

## Project Overview
This project analyzes road accident data to identify risk patterns and accident-prone areas in Pune City.

## Objectives
- Analyze road accident trends
- Identify high-risk locations
- Study accident severity
- Create interactive visualizations

## Technologies Used
- Python
- Pandas
- NumPy
- Tableau
